# Huanchen Sun's personal website

Published at https://huanchen-stack.github.io/ using GitHub Pages.

The site uses `index.html` for content and `styles.css` for its light academic layout. The homepage portrait uses `assets/huanchen-coast.jpg`, with the framing controlled in CSS so the original photo remains unchanged. Edit the files and push to `main` to update the live page. Keep publications, news, and the year in the footer current as they change.
